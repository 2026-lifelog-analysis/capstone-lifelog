# 수면 리듬 탐지기: 실행 결과 (김민준)

`run.py`를 NetHealth 하루 표(공통 `load_nethealth` 기본 전처리, 579명·355,854인일)로 돌린 결과다. 시나리오 3개, 반복 10회(seed 0~9), 구간 14일. 사람별 표(`per_person.csv.gz`)는 pid가 들어 있어 올리지 않는다.

실행 명령 (레포 맨 위 폴더에서):

```
python experiments/minjun/regularity/run.py --data data/nethealth --scenarios S14 BED-S14 JB90
```

## 1. 조건

| 항목 | 값 |
|---|---|
| 탐지기 | 걸음·취침·수면량 × (개인 z, \|개인 z\|, 개인+CUSUM) 9개 + 수면 중앙 시각 7일 SD × (개인 z, 개인+CUSUM) 2개 |
| 개인 기준선 | 직전 달력 28일, 최소 14일, z ±8 절단 (`bl.personal_z` 기본값) |
| CUSUM | k = 0.5, 경보 뒤 0으로 초기화 (`bl.cusum`과 같은 규칙) |
| 방식 A 기준값 | 대조군 전체 날의 하루 경보율 1/30 (공통 노트북 02와 같음) |
| 방식 B 기준값 | 대조군 14일 구간 오경보율 0.20 |
| 구간 선택 | `ev.inject_drift`와 같은 규칙 (직전 28일 기록 14일 이상, 구간 안 7일 이상) |
| S14 | 걸음 × 0.7, 562명 |
| BED-S14 | 취침 +120분, 기상 그대로, 564명 |
| JB90 | 취침·기상에 날마다 N(0, 90²)분 이동, 구간 안 기록 날의 이동 평균 0, 564명 |

방식 A의 CUSUM 경보선: 걸음 2.859, 취침 4.409, 수면량 3.135, 수면 중앙 시각 SD 13.227.

## 3. 수면 중앙 시각 SD 개인+CUSUM 대 수준 탐지기 중 최고

같은 사람끼리 짝지은 J 차이. CI는 사람 단위 부트스트랩 2,000회 백분위, p는 Wilcoxon 부호순위(J를 0.1 단위로 반올림).

| 시나리오 | 방식 | 수준 탐지기 중 최고 (J) | 규칙성 J | ΔJ [95% CI] | p | 사람 |
|---|---|---|---|---|---|---|
| JB90 | B | 취침 개인 z (0.132) | 0.258 | **+0.126 [+0.106, +0.147]** | < 1e−20 | 564 |
| JB90 | A | 취침 개인 z (0.168) | 0.261 | +0.093 [+0.073, +0.115] | < 1e−15 | 564 |
| BED-S14 | B | 취침 개인+CUSUM (0.594) | 0.016 | −0.577 [−0.597, −0.559] | < 1e−20 | 564 |
| S14 | B | 걸음 개인+CUSUM (0.318) | 0.000 | −0.318 [−0.336, −0.301] | < 1e−20 | 562 |

JB90의 탐지율·오경보율·지연(방식 B): 수면 중앙 시각 SD 개인+CUSUM 탐지율 0.458, 구간 오경보율 0.200, 탐지자 첫 경보 중앙 7일. 취침 개인 z 0.332, 0.200, 5일.

## 4. 읽기

- 평균이 움직이는 변화(S14, BED-S14)는 기존 탐지기가 잡고 수면 중앙 시각 SD 탐지기는 거의 못 잡는다(J 0.017 이하).
- 평균이 그대로인 흔들림(JB90)은 기존 탐지기 9개가 최고 0.132까지밖에 못 잡고, 수면 중앙 시각 SD 개인+CUSUM은 0.258이다.
- 두 종류의 탐지기가 서로 다른 변화를 보므로 한쪽이 다른 쪽을 대신하지 못한다.

## 5. 이 폴더의 코드로 다시 만들지 않은 것

- 두 경보를 "둘 중 하나라도"로 합쳤을 때 S14·BED-S14 탐지가 나빠진다는 결합 실험과, 실제 자료에서 두 경보가 같은 날 울리는 비율(Jaccard 0.071 이하)은 별도 분석에서 나온 값이다. 이 PR의 `run.py`에는 없다.
- 흔들림 크기 60·120분(JB60, JB120)은 `--scenarios`로 돌릴 수 있지만 이 문서에는 싣지 않았다.

## 6. 한계

- 흔들림은 심은 변화이고 σ = 90분은 내가 정한 크기다. 실제 생활 리듬이 무너질 때 이런 모양인지, 그것이 건강 악화보다 먼저 오는지는 이 자료로 알 수 없다.
- 공통 노트북과 같은 NetHealth 자료의 재분석이다. 독립 검증이 아니다.
- 걸음 수를 날마다 흔드는 시나리오는 점수가 없는 날을 세는 방식에 따라 결론이 갈려서 넣지 않았다.
