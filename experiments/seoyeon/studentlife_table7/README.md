# StudentLife 표 7 재현 (조서연)

Wang 외 2014(UbiComp, "StudentLife")의 표 7을 공개 데이터로 다시 계산한 코드다.
표 7은 학기 말 UCLA 외로움 점수와 스마트폰 센서 특징 6개의 상관을 보고한다.
예측 모델은 없고, 사람 단위 상관(Pearson r)만 계산한다.

| 특징 | 뜻 | 논문 r (p) |
|---|---|---|
| `act_all` | 하루 활동 시간(분) | −0.388 (.018) |
| `act_day` | 낮(9~18시) 활동 시간 | −0.326 (.049) |
| `act_evening` | 저녁(18~24시) 활동 시간 | −0.464 (.004) |
| `dist_all` | 하루 이동 거리(m) | −0.338 (.044) |
| `dist_day` | 낮 이동 거리 | −0.336 (.042) |
| `indoor_day` | 낮 실내 이동(분) | −0.332 (.045) |

## 지금 상태 (먼저 읽을 것)

- 방향은 재현된다. 6개 모두 논문처럼 음수이고, 설정을 바꾼 48개 조합에서도 전부 음수다.
- 크기는 설정에 따라 크게 달라진다. 논문에 문턱값, 날 제외 기준, 요약 방식이 적혀 있지 않아 같은 계산인지 확인할 수 없다.
- 기본값 가운데 다섯 곳이 나중에 찾은 근거와 다르다(아래 "근거와 다른 곳"). 코드는 아직 고치지 않았다. 어느 쪽으로 고칠지 정해지지 않았기 때문이다.
- 문턱값 0.1 결과는 0.5 결과를 본 뒤에 고른 값으로 돌린 것이다. 미리 정한 설정의 결과가 아니다.

## 데이터 위치

데이터는 저장소에 올리지 않는다. Kaggle에 공개된 StudentLife 데이터셋을 받아 폴더 경로를 실행 인자로 준다.
코드가 읽는 파일은 다음 네 종류다.

```
<dataset 폴더>/
├── survey/LonelinessScale.csv
└── sensing/
    ├── activity/activity_uXX.csv
    ├── gps/gps_uXX.csv
    └── wifi_location/wifi_location_uXX.csv
```

## 실행

이 폴더를 작업 위치로 두고 실행한다(모듈을 폴더 안에서 바로 불러온다). 패키지는 저장소 맨 위의 `requirements.txt`로 충분하다.

```sh
cd experiments/seoyeon/studentlife_table7
python -m pytest tests -q
python run_table7.py <dataset 폴더>
python run_table7.py <dataset 폴더> --threshold 0.1 --out results/threshold_0.1
```

결과는 이 폴더의 `results/`에 CSV 세 개로 쌓인다. `results/`는 저장소에 올리지 않는다. 사람별 표는 저장하지 않는다.

## 계산 방법

| 단계 | 내용 | 파일 |
|---|---|---|
| 외로움 점수 | 응답을 1~4점으로 바꿔 20문항을 더함. 9문항(1, 5, 6, 9, 10, 15, 16, 19, 20)은 역채점. 문항이 하나라도 비면 총점을 내지 않음 | `scoring.py` |
| 시간 | 기록 시각을 미국 동부 시각으로 바꿈. 밤 0~9시, 낮 9~18시, 저녁 18~24시 | `features.py` |
| 활동 시간 | 10분 구간마다 (걷기+뛰기 판정 수 ÷ 전체 판정 수)가 문턱값보다 크면 10분으로 셈. 하루 단위로 더함 | `features.py` |
| 이동 거리 | 같은 날 안에서 이어진 GPS 표본 사이의 구면 거리를 더함. 낮 거리는 두 끝점이 모두 낮일 때만 | `features.py` |
| 실내 이동 | 10분 구간의 와이파이 위치 기록 중 `in[...]`이 절반 이상이면 건물 안 구간. 그 구간의 걷기 비율 × 10분 | `features.py` |
| 사람 단위 요약 | 144개 구간 중 72개 이상 기록된 날만 써서 평균(이동 거리에는 이 규칙을 적용하지 않음) | `table7.py` |
| 상관과 비교 | Pearson r과 양측 p. 논문 값과의 차이, 부호 일치, ±0.10 안 여부 | `table7.py` |
| 민감도 | 논문에 없는 선택을 바꿔 가며 다시 계산(활동 32, 이동 거리 8, 실내 이동 8 조합) | `run_table7.py` |

## 결과

대상은 학기 말 UCLA 점수가 있는 37명이고, 총점은 40.9 ± 10.5로 논문 표 4와 같다.

**문턱값 0.5 (결과를 보기 전에 정한 기본값)**

| 특징 | r | p | 논문 r | 차이 |
|---|---|---|---|---|
| `act_all` | −0.217 | .197 | −0.388 | 0.171 |
| `act_day` | −0.158 | .351 | −0.326 | 0.168 |
| `act_evening` | −0.302 | .069 | −0.464 | 0.162 |
| `dist_all` | −0.277 | .097 | −0.338 | 0.061 |
| `dist_day` | −0.303 | .068 | −0.336 | 0.033 |
| `indoor_day` | −0.292 | .080 | −0.332 | 0.040 |

부호 일치 6/6, ±0.10 안 3/6, p < .05인 것은 없다.

**문턱값 0.1 (결과를 본 뒤에 고른 값)**

| 특징 | r | p | 논문 r | 차이 |
|---|---|---|---|---|
| `act_all` | −0.330 | .046 | −0.388 | 0.058 |
| `act_day` | −0.308 | .064 | −0.326 | 0.018 |
| `act_evening` | −0.363 | .027 | −0.464 | 0.101 |

이동 거리와 실내 이동은 문턱값과 무관해 위 표와 같다. 부호 일치 6/6, ±0.10 안 5/6.

**민감도 (기본 설정 기준, 조합별 r의 범위)**

| 특징 | 가장 강한 r | 가장 약한 r | 조합 수 |
|---|---|---|---|
| `act_all` | −0.350 | −0.104 | 32 |
| `act_day` | −0.326 | −0.097 | 32 |
| `act_evening` | −0.392 | −0.173 | 32 |
| `dist_all` | −0.277 | −0.149 | 8 |
| `dist_day` | −0.303 | −0.192 | 8 |
| `indoor_day` | −0.292 | −0.007 | 8 |

**판정 기준에 대해.** ±0.10은 근거 없이 정한 기준이다. Hardwicke 외 2018은 보고값 대비 오차 비율 10%를 경계로 쓰고, p값이 0.05의 반대편으로 넘어가면 따로 오류로 분류한다. 이 기준으로 10% 안에 드는 것은 문턱값 0.5에서 1개(`dist_day`), 0.1에서 2개(`act_day`, `dist_day`)다.

## 근거와 다른 곳 (코드는 아직 그대로)

| 결정 | 지금 코드 | 찾은 근거 |
|---|---|---|
| 역채점 문항 | 9문항 | 설문 파일의 문항은 1980년 개정판(Russell, Peplau & Cutrona 1980, 표 1)과 같고, 그 채점표는 4번을 포함한 10문항 역채점이다. 다만 논문 표 4의 40.9 ± 10.5는 9문항 채점으로만 나온다(10문항이면 39.3 ± 11.5). `scoring.py` 머리말의 "3판" 표기도 이 점에서 정확하지 않다 |
| 문턱값 | 0.5, 후보 0.1~0.3 | 같은 표본·같은 앱·같은 저자진의 Ben-Zeev 외 2015가 0.5로 적는다. 단 비율을 "움직임 대 정지"로 적어 전체 대비인지 정지 대비인지는 문장만으로 갈리지 않는다. 0.1~0.3의 근거는 찾지 못했다 |
| 날 제외 | 72구간(12시간) 이상 | 같은 연구실의 CrossCheck(Wang 외 2016)는 19시간 미만인 날을 버린다. Adler 외 2022가 공개 StudentLife에 같은 기준을 적용했다. 12시간의 근거는 찾지 못했다 |
| 실내 이동 | 걷기 비율 × 10분 | 논문은 건물 안일 때 걷기 추론으로 "활동 시간"을 계산한다고 적고, 활동 시간은 문턱값을 넘는 10분 구간의 합으로 정의한다. 구간을 통째로 세는 쪽(`indoor_method="active"`)에 가깝게 읽힌다 |
| GPS 필터 | 없음 | RAPIDS 기본값은 정확도 100m 이상 제거, 시속 250km 초과 제거다. 지금 계산에는 하루 100km를 넘는 날이 100개(22명) 있다 |

## 나머지 결정의 근거

"직접"은 원문을 읽어 확인한 것, "보고"는 조사 보고만 받고 원문과 대조하지 못한 것이다.

| 결정 | 근거 |
|---|---|
| 거리는 연속 표본 간 거리의 합 | Saeb 외 2015가 같은 정의를 쓴다(직접). RAPIDS는 시속 1km 이상 이동한 행만 더한다(보고) |
| 낮 거리는 두 끝점 모두 낮 | niimpy, Canzian & Musolesi 2015가 구간으로 먼저 거른 뒤 계산한다(보고). RAPIDS는 겹친 시간만큼 나눠 싣는다(보고) |
| `near[...]`는 건물 안이 아님 | 데이터 문서가 "건물 안"과 "여러 건물 근처"를 구분하고, 논문은 특정 건물 안일 때만 계산한다(직접). near 처리 문장 자체는 없다 |
| 사람 단위 평균 | SmartGPA(Wang 외 2015)가 2014 연구를 활동 시간·실내 이동의 평균과의 상관으로 서술한다(직접). Wang 외 2018도 학기 평균을 쓴다(직접) |
| 양측 p값 | 표 7의 6개 중 5개가 37명 양측 값과 일치한다(직접 계산). 하루 이동 거리만 36명일 때 일치한다 |
| 빈 문항이 있으면 총점 미산출 | 척도 저자의 규칙은 찾지 못했다. 설문에 빈 문항이 0건이라 결과에 영향이 없다(직접) |
| "알 수 없음" 판정을 분모에 포함 | 저자 규칙은 찾지 못했다. Wu & Solmaz 2018은 제외한다(직접). 공개 코드는 포함과 제외가 모두 있다(보고) |
| 자정을 넘는 구간 제외 | 논문 서술은 찾지 못했다. RAPIDS는 버리지 않고 나눠 싣는다(보고) |
| 건물 안 판정 "절반 이상" | 어떤 논문·문서·코드에서도 찾지 못했다 |
| 민감도 후보 값 | 그럴듯한 대안은 모두 넣고 열등한 것은 빼라는 원칙만 있다(Steegen 외 2016, Simonsohn 외 2020, 보고). 정확도 100m는 RAPIDS와 같고, 간격 3600초와 문턱값 0.1~0.3은 출처가 없다 |

열지 못한 자료: UCLA 3판 원문(Russell 1996), Harari 외 2017, Rui Wang 학위논문, BeWell·Jigsaw 논문.

다른 팀 결과: Li 외 2016이 같은 공개 데이터로 활동 시간 −0.387, 낮 −0.315, 저녁 −0.425, 낮 실내 이동 −0.341을 보고한다. 계산 방법이 적혀 있지 않고 표의 p값이 한 가지 인원 수로 맞지 않아 근거로는 약하다.
