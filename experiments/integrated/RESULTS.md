# 통합 평가: PR 1·3·4의 점수를 같은 조건으로 다시 잰 결과

네 PR은 각자 다른 조건(사람 분할, 기준값 규칙)으로 채점해서 본문 수치를 나란히 놓을 수 없었다. 여기서는 공통 `evaluate_injection`을 한 번 부르고, 점수 함수 자리에 공통 5개 + PR 1 변형 3개 + PR 3 지표 2개, 열 11개를 넣어 같은 사람·같은 구간·같은 변화·같은 기준값 규칙으로 다시 쟀다. 공통 코드(`src/`)는 고치지 않았고, PR 1·3의 점수는 main에 있는 함수를 그대로 불렀다.

실행: `python experiments/integrated/run_all.py --data data/nethealth` (반복 10회, 시나리오 5개, 약 1시간). 결과 CSV는 `results/integrated/`에 있고 올리지 않는다.

## 7. 조건 차이와 한계

- **PR 1의 참고 집단.** PR 1은 주입 없는 70%를 참고 집단으로 두고 그날 중앙값을 구했다. 여기서는 전원이 평가 대상이라 참고 집단이 없고, 그날 중앙값에 심은 변화가 조금 섞인다. 사람마다 구간이 달라 같은 날 겹치는 사람은 적지만, 0은 아니다. 5절의 작은 차이가 그 흔적이다.
- **PR 1 변형을 잠든 시각·흔들림에도 적용했다.** PR 1 본문은 걸음만 평가했다. 그 두 열은 이번에 처음 돌린 값이다.
- **흔들림 시나리오는 별도 루프다.** 공통 함수가 못 심어서 PR 3 함수로 심고 같은 세는 법으로 셌다. 5절의 대조로 세는 법이 같음을 확인했지만, 공통 함수 한 번 호출로 나온 값은 아니다.
- **PR 3 지표의 잠든 시각 +120분 처리.** 공통 주입은 잠든 시각만 +120분 옮기고 깬 시각은 두므로 수면 중앙 시각은 +60분 움직인다. PR 3의 자체 실행과 같은 처리이지만, 깬 시각이 자정을 넘는 소수의 날에서 값이 조금 다르다(0.016 대 0.022).
- **CUSUM 기준값.** 방식 A에서 공통 함수는 `score_fn` 경로의 모든 열을 분위수로 긋는다. CUSUM 안의 초기화선 h와 그 분위수는 조금 다를 수 있다(PR 2 실측: 방법당 1인일). 방식 C는 h 자체를 맞춘다. 두 방식의 순위가 같으므로 결론에는 영향이 없다.
- **같은 자료의 재분석.** 네 PR과 같은 NetHealth이고 반복 탐색에 쓰인 자료다. 독립 검증이 아니다.
