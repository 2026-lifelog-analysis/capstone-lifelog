# ETRI 제5회 수상작 재현 (춘자·LOV3) — PMData

후속 연구(설문이 드물 때의 개인 상태 추적)의 전제 두 개를 다른 데이터에서 확인한다.

1. **춘자 (State, not Trait, 장려상):** 매일 예측의 대부분은 그 사람의 평소 상태(개인 양성 비율)에서 나온다.
2. **LOV3 (Structure over Scale, 최우수상):** 그 평소 상태가 같은 사람 안에서도 시기마다 바뀐다.

절차와 성공 기준은 실행 전에 고정했고, 원 논문과 다른 점·결과·한계는 재현 실험 기록 문서에 있다.

## 실행

```bash
pip install lightgbm   # requirements.txt에 추가함
python3 -I pm_build.py data/pmdata data/pm_daily.pkl
python3 -I repro_chunja.py data/pm_daily.pkl results/repro_pmdata
python3 -I repro_lov3.py data/pm_daily.pkl results/repro_pmdata
```

- `data/pmdata/`에는 `p01`~`p16` 폴더(각 `pmsys/wellness.csv`, `fitbit/sleep.json` 등)가 있어야 한다. 데이터는 저장소에 올리지 않는다.
- 사용한 데이터는 PMData의 GitHub 미러 [itsalamhere/sports-logs](https://github.com/itsalamhere/sports-logs) 커밋 590f469다. 공식 배포처(Simula, Kaggle)는 작업 환경에서 접속이 막혀 있었다. 사람 수(16명)와 기간(2019-11~2020-03)은 공식 설명과 같다.
- 전체 실행은 30초 안쪽이다.

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `pm_build.py` | 원본 → 사람-일 표. t일 설문에는 t일 아침에 끝난 수면과 t−1일까지의 활동만 붙인다 |
| `repro_chunja.py` | 춘자 4단계 비교(전체 비율 → 개인 비율 → LightGBM → 수축), ICC, 센서 연결도 λ, 사람 단위 부트스트랩 2,000회 |
| `repro_lov3.py` | 전날 라벨 상관, 개인 비율의 전반→후반·28일 블록 간 변화, 같은 사람 안에서 날짜를 섞은 데이터 200회와 비교 |
| `summary_pmdata/` | 집계 결과만 (원자료 없음) |

## 결과 요약 (2026-11-21)

| 확인할 것 | 결과 | 판정 |
| --- | --- | --- |
| 개인 비율이 예측의 대부분인가 (춘자) | 평균 log loss: 전체 비율 0.672 → 개인 비율 0.594 → 센서 추가 0.589. 센서 이득 +0.005 [−0.004, +0.018] | 재현 |

| 개인 비율이 움직이는가 (LOV3) | 전반→후반 변화: 주관 라벨 6개 평균 0.133 (원 논문 0.148). 6개 중 5개가 섞은 데이터의 95% 분위를 넘음. 28일 블록으로는 3개 | 재현 |

## 원 논문과 다른 점 (요약)

- 평가 집합: 원 논문은 테스트와 비슷한 학습 행 상위 25%, 여기서는 사람별 시간순 앞 50% 학습 / 뒤 50% 평가(경계 7일 간격).
- 모델: 원 논문은 스태킹 앙상블에 피처 약 330개, 여기서는 LightGBM 하나에 피처 70개. target encoding 대신 학습 구간 개인 비율 하나를 피처로 썼다.
- λ: 원 논문은 ℓ2 로지스틱, 여기서는 릿지 회귀. 예측 대상(라벨 − 개인 비율)이 연속값이기 때문이다.
- 객관 라벨: Fitbit은 효율·잠드는 데 걸린 시간·깨어난 시간이 거의 한 값이라 총수면 7~9시간 하나만 썼다.
