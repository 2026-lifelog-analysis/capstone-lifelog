# ETRI 제5회 수상작(춘자·LOV3) 재현과 후속 실험

두 수상작의 분석 틀과 검증 방식을 그대로 옮기고, 두 결과를 합친 "움직이는 개인 기준선 추적"을 붙였다. 그다음 설문이 드물 때도 기준 이상의 성능이 나오는지 확인한다.

| 질문 | 내용 | 출처 |
| --- | --- | --- |
| RQ1 재현 | 매일 예측의 대부분이 개인 평소 비율에서 나오는가 | 춘자 (State, not Trait, 장려상) |
| RQ2 재현 | 평소 비율이 같은 사람 안에서 시기마다 움직이는가 | LOV3 (Structure over Scale, 최우수상) |
| RQ3 제안 | 설문이 3일·7일에 한 번이거나 실제 저응답 패턴일 때, 추적 방식이 기존 방법보다 나은가 | 후속 |
| RQ4 외부 확인 | 추적한 상태가 센서와 무관한 사건·표준 척도와 맞물리는가 | 후속 |

절차와 판정 기준은 실행 전에 고정했고, 원 논문과 다른 점·결과·한계는 재현 실험 기록 문서에 있다.

## 실행

```bash
pip install -r requirements.txt          # lightgbm 포함
D="/mnt/c/Users/<사용자>/공유폴더/동국대/2026-2/종설1/data"
bash experiments/seungho/repro_winners/run_all.sh "$D" results/repro
```

- `$D` 아래에 `pmdata/`(p01~p16), `HumanRhythms/`(Cleaned_Raw_Data, Additional_Data), `ch2025_metrics_train.csv`가 있어야 한다.
- 약 10분 걸린다. 결과는 `results/repro/{pm,hr,etri}/`에 생기고, `results/`는 깃에 올라가지 않는다.
- ETRI는 라벨 파일만 읽고 집계값만 쓴다. ETRI 원자료는 AI 도구에 열지 말고 터미널에서만 실행한다.
- `python3 -I`로 실행하면 `pip --user`로 깐 패키지를 못 찾는다. `run_all.sh`는 `-I` 없이 실행한다.

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `common.py` | 사람-일 표 규약, 분할, ICC, 부트스트랩, Holm |
| `pm_build.py` / `hr_build.py` | 원본 → 사람-일 표. t일 설문에는 t일 아침에 끝난 수면과 t−1일까지의 활동만 붙인다 |
| `repro_chunja.py` | 춘자 4단계 비교(전체 비율 → 개인 비율 → LightGBM → 수축), ICC, 센서 연결도 λ |
| `repro_lov3.py` | 전날 라벨 상관, 개인 비율 변화. 같은 사람 안에서 날짜를 섞은 데이터 200회와 비교 |
| `sparse_survey.py` | RQ3. B1 고정 비율, B2 센서 모델, B3 라벨 자기상관(LOV3), P1 상태공간 추적, P2 P1 + 센서 |
| `external_check.py` | RQ4. 시험·방학·부상 전후 변화, 연구 전후 PSQI·SF-12 문항 변화와의 상관 |
| `etri_icc_check.py` | 구현 검증. ETRI 라벨의 ICC·전날 상관을 두 논문 보고값과 비교 |
| `summary_pmdata/`, `summary_hr/` | 2026-11-23 실행의 집계 결과 (원자료 없음) |

**한 줄 결론:** 두 수상작을 합친 상태공간 추적(P1)은 설문이 7일에 한 번이어도 평균 log loss가 고정 비율(춘자)보다 0.020~0.024, 라벨 자기상관(LOV3)보다 0.011~0.012 낮다. HR에서는 라벨·예산 대부분에서 유의했고, PMData에서는 평균만 낮고 대부분 유의하지 않았다. 센서를 넣은 P2는 P1과 거의 같아서, "센서가 설문 공백을 메운다"는 가설은 지지되지 않았다.

## 원 논문과 다른 점 (요약)

- 평가 집합: 원 논문은 테스트와 비슷한 학습 행 상위 25%, 여기서는 사람별 시간순 앞 50% / 뒤 50%(경계 7일).
- 모델: 원 논문은 스태킹 앙상블에 피처 약 330개, 여기서는 LightGBM 하나에 피처 약 70개.
- λ: 원 논문은 ℓ2 로지스틱, 여기서는 릿지 회귀(예측 대상이 연속값).
- PMData 객관 라벨은 총수면 1개뿐이다. Fitbit의 효율·잠들기까지 걸린 시간·깨어 있던 시간이 거의 한 값이다.
- P2의 센서 항은 설계 문서의 상태 방정식이 아니라 관측식(p = σ(m + β·z))에 넣었다. 매일 βΔs를 더하면 값이 발산하기 때문이다.
- RQ4의 PSQI·SF-12는 총점이 아니라 단일 문항(전반적 수면의 질, 전반적 건강)이다.
